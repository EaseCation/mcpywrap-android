# 产品界面规范

组件基线为官方 Jetpack Compose Material 3 **1.4.0**（与 `core/designsystem/build.gradle.kts` 一致）。主题和几何令牌由 `core:designsystem` 提供。

- 以 4 dp 为基础栅格；元素间距 8/12 dp、卡片间距 16 dp、区段间距 24 dp。
- 手机内容左右边距 20 dp；宽度达到 600 dp 后使用 32 dp 边距。主内容居中，最大宽度 840 dp。
- 同一内容列中的卡片全部等宽。卡片圆角 20 dp、内部衬底 16 dp；小控件 8 dp、对话框和底部抽屉 28 dp，按钮保留 Material 胶囊形状。
- 卡片内边距 20 dp。嵌入的列表项背景透明，不能出现矩形内底色；无操作的按钮行不占空间。
- 主 Tab 只在顶栏显示页面主标题，内容区用 titleMedium 标识区段；详细说明使用 bodyMedium/bodySmall。
- 状态用图标、文字与颜色共同表达。常规结束和诊断不确定性使用中性文字；只有需要采取措施的错误才强调。
- 主操作使用实色按钮，次操作使用描边、色调或文字按钮；按钮组允许换行，触控目标至少 48 dp。
- 开发页的协作关系图始终可见，连接状态使用单行开关。系统权限按使用场景出现。
- 日志与源码编辑保留连续、紧凑的阅读布局，不套用逐行卡片样式。

产品卡片使用 Compose 原生 `dropShadow` 双层柔影：扩散层半径 32 dp、向下 12 dp、浅色透明度 3%；接触层半径 8 dp、向下 2 dp、浅色透明度 1%。深色主题分别使用 12% 和 6%，并保留表面色差。卡片自身 elevation 为零，避免叠加短而深的边缘阴影。

浅色页面底色使用中性淡灰 `#F3F4F6`，主要卡片使用 `#FFFFFF`，绿色仅承担品牌、操作和选中状态。深色主题使用中性深灰表面色阶，保持相同的信息层级。
